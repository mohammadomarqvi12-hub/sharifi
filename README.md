# صرافی شریفی | Sharifi Exchange

نسخهٔ آغازین یک وب‌اپلیکیشن برای مدیریت درخواست‌های خریدوفروش اسعار، نرخ‌ها، پیام مشتریان، تکت‌های پشتیبانی و رسیدهای قابل چاپ.

## امکانات پیاده‌سازی‌شده
- رابط کاربری دری و راست‌به‌چپ، واکنش‌گرا برای موبایل و دسکتاپ
- ساخت حساب مشتری و ورود امن با هش رمز عبور PBKDF2
- توکن CSRF برای فرم‌های POST
- مدیریت نرخ خرید و فروش و ثبت تاریخچهٔ نرخ
- محاسبه‌گر ارز به افغانی
- ثبت درخواست خرید/فروش و پیگیری وضعیت
- ثبت معاملهٔ تکمیل‌شده توسط کارمند مجاز و تولید رسید قابل چاپ/PDF
- پیام‌رسانی داخل حساب
- تکت پشتیبانی و پاسخ کارمند
- داشبورد مدیریت، آمار اولیه و خروجی CSV معاملات
- پایگاه داده SQLite برای اجرای آزمایشی
- اسکناس‌های تزئینی ساخته‌شده با CSS؛ برای تصاویر واقعی باید فایل/منبع دارای مجوز پیکربندی شود.

## نیازمندی‌ها
- Python 3.10 یا جدیدتر
- pip

## اجرای محلی
### Linux / macOS
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export SHARIFI_SECRET_KEY="$(python -c 'import secrets; print(secrets.token_hex(32))')"
export SHARIFI_SETUP_KEY="$(python -c 'import secrets; print(secrets.token_urlsafe(32))')"
python app.py
```

### Windows PowerShell
```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:SHARIFI_SECRET_KEY = "یک-کلید-طولانی-تصادفی-و-خصوصی"
$env:SHARIFI_SETUP_KEY = "یک-کلید-راه‌اندازی-تصادفی-و-خصوصی"
python app.py
```

باز کنید: `http://127.0.0.1:5000`

## ساخت حساب مدیر اصلی
1. هنگام اجرای نخستین بار، متغیر `SHARIFI_SETUP_KEY` را در محیط تنظیم کنید.
2. به `/admin/setup` بروید.
3. کلید راه‌اندازی را وارد کنید و مدیر را بسازید.
4. پس از ساخت مدیر، صفحهٔ راه‌اندازی خودکار غیرفعال می‌شود.
5. کلید راه‌اندازی را در محیط میزبانی حذف یا عوض کنید و هیچ‌گاه آن را با دیگران شریک نسازید.

## نکات مهم
- نرخ‌ها عمداً به‌صورت خودکار از وب‌سایت‌های نامشخص کپی نمی‌شوند. مدیر باید نرخ معتبر را ثبت کند یا یک API مجاز را جداگانه پیکربندی نماید. این پروژه در حال حاضر API نرخ زنده ندارد.
- تصاویر اسکناس واقعی از وب‌سایت‌ها به‌صورت خودکار دانلود نمی‌شوند؛ پس‌زمینه فعلی طرح تزئینی CSS است. برای استفاده از تصاویر واقعی، مجوز استفاده و منبع قابل اعتماد را بررسی کنید.
- این پروژه یک نسخهٔ آغازین قابل اجرا و آزمایش است، نه محصولی که بدون بازبینی امنیتی و تست مستقل آمادهٔ نگهداری پول یا انتقال واقعی وجه باشد.
- پیش از استفادهٔ عملیاتی، از HTTPS، WSGI production server، پایگاه دادهٔ مناسب production، پشتیبان‌گیری، مانیتورینگ، محدودسازی تلاش ورود، MFA مدیر، بررسی امنیتی و مشورهٔ حقوقی/حسابداری استفاده کنید.
- انتقال پول، پرداخت آنلاین و حواله فعال نیست. جواز و اتصال مالی مجاز باید جداگانه بررسی و پیاده‌سازی شود.
- تاریخ‌ها در این نسخه با زمان محلی سرور ثبت می‌شوند. برای production سرور را روی Asia/Kabul تنظیم کنید و بررسی timezone انجام دهید.
- هیچ نرخ نمونه‌ای از قبل وارد نشده است؛ اعداد ساختگی به‌عنوان نرخ واقعی نمایش داده نمی‌شوند.

## محدودیت‌های نسخهٔ فعلی
- پایگاه دادهٔ SQLite برای نمونهٔ اولیه است؛ برای چندکاربرهٔ production PostgreSQL توصیه می‌شود.
- ایمیل/SMS، تأیید تلفن، بازیابی رمز از طریق ایمیل، آپلود فایل، real-time WebSocket، چندمرحله‌ای مدیر، provider تصاویر و API نرخ زنده هنوز به سرویس بیرونی متصل نیستند.
- پیام‌رسانی به شکل تازه‌سازی صفحه کار می‌کند و WebSocket زنده نیست.
- سیستم گزارش‌گیری مالی و سود حسابداری کامل نیست؛ خروجی CSV معاملات فراهم شده است.
- قبل از راه‌اندازی عمومی، آزمایش و بازبینی تخصصی ضروری است.
